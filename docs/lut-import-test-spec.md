# 既存LUT読み込み テスト仕様書

`lut-import-design.md` と `requirements.md` の F8 を正とし、テストは実装ではなくこれらの仕様から作成する。
テストケースは `IMP-` 接頭辞の ID で管理し、実施結果は表で報告する。

## 構成

- **単体テスト**：Vitest で `tests/import.test.ts` に実装する。対象は `src/engine` の純粋関数であり、DOM・WebGL・ファイルシステムには依存しない。
- **手動確認（E2E）**：ブラウザ上のUI挙動は手動またはCDP経由で確認する。手順は `.agents/skills/testing-lut-studio` の知見に従う。

## 単体テスト

### `.cube` パース（IMP-01〜IMP-06）

| ID | 項目 | 手順・入力 | 期待結果 |
|----|------|------------|----------|
| IMP-01 | 最小限の `.cube` を解析できる | size=2 の `.cube`（ヘッダ＋8行）を `parseCubeLut` に与える | `LutData.size===2`、データ長 8×3。各行が規約の入力格子に対応する |
| IMP-02 | 軸順を正しく内部表現へ変換する | 非対称LUT（全格子で既知の写像、例: 出力=(b,r,g)）を書き出した `.cube` を読み戻す | 読み戻した `LutData` が元LUTと全格子一致する（許容誤差は書き出し精度の1e-5程度） |
| IMP-03 | コメント・空行・改行コード・空白を許容する | `#` コメント行、空行、行頭空白、タブ区切り、CRLF を混ぜた `.cube` | IMP-01と同じ `LutData` が得られる |
| IMP-04 | `LUT_3D_SIZE` 必須と範囲を検査する | キーワード欠落、size=1、size=257、非整数（33.5）を与える | それぞれエラーになる |
| IMP-05 | データ行の個数と数値性を検査する | 行数不足、超過、数値以外のトークン、1行が2要素だけ | それぞれエラーになる。可能なら行番号がメッセージに含まれる |
| IMP-06 | `LUT_1D_SIZE` を含む入力を拒否する | 1Dのみ、1D+3D併記の両パターン | それぞれエラーになる |
| IMP-07 | `DOMAIN_MIN`/`DOMAIN_MAX` を保持する | ドメイン (0,0,0)〜(2,2,2) のヘッダを与える | `domainMin`/`domainMax` にその値が入る。省略時は (0,0,0)〜(1,1,1) |
| IMP-08 | 値の範囲外はクランプする | 負値や 1.0 超のデータ行を含む `.cube` | 0〜1 にクランプされる |
| IMP-09 | `TITLE` を保持する | `TITLE "foo"` あり／なしの `.cube` | あり→`title==="foo"`、なし→`undefined` |
| IMP-10 | ドメインの妥当性を検査する | `domainMax_i <= domainMin_i`（ゼロ幅・逆転）、非有限値 | それぞれエラーになる |

### PNG画像LUT（IMP-11〜IMP-16）

| ID | 項目 | 手順・入力 | 期待結果 |
|----|------|------------|----------|
| IMP-11 | HaldCLUT寸法を判別する | 512×512（L=8）と 216×216（L=6）を `detectImageLutLayout` に与える | それぞれ `"hald"` |
| IMP-12 | ReShade寸法を判別する | 4096×64（size=64）と 1024×32（size=32） | それぞれ `"reshade"` |
| IMP-13 | 署名のない寸法を拒否する | 500×500、640×480、4096×63 等 | `null` |
| IMP-14 | HaldCLUT書き出しと往復一致する | 非対称LUT(size=64)を `lutToHald` → `imageToLut(img,"hald")` | 全格子が `round(v*255)/255` の量子化を経て一致する |
| IMP-15 | ReShade書き出しと往復一致する | 非対称LUT(size=64)を `lutToReShade` → `imageToLut(img,"reshade")` | 同上 |
| IMP-16 | 不透明でない画素を拒否する | アルファが255以外の画素を1つ以上含む `RgbaImage` | `imageToLut` がエラーになる |

### ベースLUT合成（IMP-21〜IMP-26）

| ID | 項目 | 手順・入力 | 期待結果 |
|----|------|------------|----------|
| IMP-21 | base=null で既存経路と等価 | `withBaseLut(null, t)` が `t` と同じ出力を返す | 恒等変換を通すと中立LUTと一致する |
| IMP-22 | ベースLUTが先に適用される | base=チャネル交換LUT（out=(b,r,g)）、next=彩度-1、入力=純赤(1,0,0) | 出力≈(0.7152,0.7152,0.7152)（赤→緑→輝度脱色）。調整が先なら赤→輝度0.2126のグレーになるため、値で順序を区別できる |
| IMP-23 | 中立調整のときベースLUTそのものになる | base=任意のLUT、next=中立調整 | 焼き付け結果はベースLUTの各格子点を三線形補間した値になる |
| IMP-24 | サイズ差をリサンプルする | base=size17、焼き付けsize=64 | 格子点どうしで連続し、既知の写像（例: 中立LUT）ではほぼ恒等になる |
| IMP-25 | ドメイン正規化が働く | base=size2、ドメイン0〜2 の `.cube` | 入力0.5が格子座標0.25として引かれる |
| IMP-26 | PNG由来ベースLUTの8bit誤差を許容する | HaldCLUT画像をbaseに合成 | 各格子で誤差が ±1/255+ε の範囲内 |
| IMP-28 | 適用強度が線形補間で効く（仕様決定W） | base=非恒等LUT、strength=0 / 0.5 / 1 | 0→入力そのまま（ベースLUTなしと同等）、0.5→入力と適用結果の中間、1→フル適用 |

## 手動確認（E2E）

UI側の項目。`testing-lut-studio` の手順でブラウザを操作し、ファイル投入はCDPの `DOM.setFileInputFiles` を使う。

| ID | 項目 | 手順 | 期待結果 |
|----|------|------|----------|
| IMP-31 | 「LUTを読み込み」から `.cube` を適用 | パネルのボタンから既知の `.cube`（例: 自前で書き出したもの）を選択 | プレビューに反映され、ステータスにファイル名とサイズが出る |
| IMP-32 | ドロップゾーンに `.cube` をドロップ | 画像と `.cube` を混ぜてドロップ | 画像は一覧に追加され、`.cube` はベースLUTになる |
| IMP-33 | 写真PNGは画像として読み込まれる | ドロップゾーンに通常写真のPNGをドロップ | LUTではなくプレビュー画像として追加される |
| IMP-34 | PNG画像LUTをボタン経由で読み込む | 「LUTを読み込み」から自前書き出しのHaldCLUT PNGを選択 | ベースLUTとして適用され、プレビューが中立に近い見た目になる |
| IMP-35 | 解除で中立に戻る | ベースLUT適用後に「解除」 | プレビューが中立LUTに戻る |
| IMP-36 | 調整がベースLUTの後段に効く | ベースLUT適用後にスライダ（例: 露出）を動かす | ベースLUTの出力に追加で調整が乗る |
| IMP-37 | エラー表示 | 不正な `.cube`、署名のないPNGをボタンから読み込む | ステータスに日本語のエラーメッセージ。既存ベースLUTは維持される |
| IMP-38 | プリセットにベースLUTを含まない | ベースLUT適用→プリセット保存→ベースLUT解除→プリセット読込 | プリセット読込でベースLUTは復活しない（中立のまま） |
| IMP-39 | 再読み込みでベースLUTを置き換える | 2つの異なる `.cube` を続けて読み込む | 後者が有効になり、表示名も後者になる |
| IMP-40 | モバイル版では読み込みUIを表示しない | 幅390pxエミュレーションで調整パネルを確認 | 「LUTを読み込み」ボタンとベースLUTセクションが表示されない（LUT書き出しと同じ非表示規則） |
| IMP-41 | 形式変換として使える | size=33の `.cube` 読み込み→PNG（ReShade）で書き出し | 書き出したPNGが同一写像を表す（size=64へリサンプルされるため格子値の一致ではなく、再読み込みしてプレビューが同一見た目になることで確認する） |
| IMP-42 | 適用強度スライダーがプレビューと書き出しに効く（仕様決定W） | ベースLUT適用後に「適用強度」を100→50→0と動かす | 50でベースLUTの効果が半分になり、0で中立と同じ見た目に戻る。書き出したLUTにも同じ強度が反映される。ベースLUT解除後はスライダーが消える |
