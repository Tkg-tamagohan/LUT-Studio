# 調整項目ガイド

この文書は、調整パネルの各項目が何を変え、どの値域で、どの方向へ効果を持つかを説明する利用者向けの資料である。
仕様の正は `requirements.md` と `decision-records.md` にある。ここでは各調整の意味と使いどころに絞って述べる。

## 適用順序

調整は次の順で画素へ適用される。

ベースLUT → 露出 → 色温度 → コントラスト → 彩度 → 色相回転 → アイソレーション → カーブ → リフト・ガンマ・ゲイン

この順序は見直しが進行中であり、アイソレーションの位置を選択式にする変更も予定されている。
本節の順序は現行実装のものであり、将来の変更で前後し得る。

## ベースLUT

外部のLUT（.cube またはPNG画像LUT）を読み込み、すべての調整の前段に適用する。
読み込んだLUTを出発点にして、手元の調整で仕上げを変える用途に向く。
適用強度は0〜100%で、0%は未適用（読み込みなしと同じ）、100%でフル適用となる。

## 露出

EV段で全体の明るさを変える。
各画素に2のEV乗を乗算するため、+1で2倍、-1で半分の明るさになる。
範囲は-3〜3、中立は0。正で明るく、負で暗くなる。

## 色温度

画面全体を暖色または寒色へ寄せる。
範囲は-1〜1、中立は0。正の値は赤を増して青を減らす（暖色方向）、負の値はその逆（寒色方向）になる。
照明のオレンジ被りを抑える、日没の暖かさを足すなどの用途に向く。

## コントラスト

明暗の差を拡縮する。
範囲は-1〜1、中立は0。中間の明るさ（0.5）を支点に広げるため、正の値で明暗差が強まり、負の値で弱まる。

## 彩度

色の鮮やかさを変える。
範囲は-1〜1、中立は0。輝度（Rec.709係数）からの距離を拡縮するため、正の値で鮮やかになり、負の値で彩度が落ち、-1で輝度だけの無彩色になる。

## 色相回転

明るさと彩度を保ったまま、色味だけを色相環上で回転させる。
範囲は-180〜180度、中立は0。
装備や空の色を別の色相へずらす用途に向く。

## アイソレーション（分離）

選択した色相範囲の彩色だけを残し、範囲外を脱色する部分色残しである。
選択対象は複数登録でき、それぞれ中心色相（0〜360度）、範囲（0〜180度）、ぼかし（0〜90度）で指定する。
強度は0〜1で、1で範囲外が完全なモノクロ、0で効果なしになる。
中心色相はスライダ、カラーピッカー、プレビュー画像上のクリック（スポイト）で指定できる。
マスクプレビューを有効にすると選択範囲が白黒で確認できる。これは表示専用であり、書き出すLUTには含まれない。
用途例は、肌色だけを残して背景を脱色する、特定のオブジェクトの色だけを目立たせる、といった使い方である。

## カーブ

マスターとRGB各チャネルの区分線形カーブである。
入力0〜1に対して出力0〜1を通る制御点を配置し、点の間は直線で補間される。
マスターは全体の明暗、RGB各チャネルはそのチャネル単独のトーンを変える。
既定の2点（(0,0)と(1,1)を結ぶ直線）が中立である。
シャドウを持ち上げたフィルム調や、片チャネルだけを歪める色かぶりなどに使う。

## リフト・ガンマ・ゲイン

シャドウ、ミッドトーン、ハイライトの三色調を、RGB各チャネルで補正する。

- **リフト**：暗部の底上げ・底下げ。各色-1〜1、中立は0。正で暗部が持ち上がり、負で沈む。
- **ガンマ**：中間調の歪み。各色0より大きい値（スライダは0.2〜4）、中立は1。大きい値で中間調が明るく、小さい値で暗くなる。
- **ゲイン**：ハイライト側の伸縮。各色0より大きい値（スライダは0.2〜4）、中立は1。

影側に青を乗せてハイライトを暖かく残す、といった輝度帯ごとの色味分けに使う。
