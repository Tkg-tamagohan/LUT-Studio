# LUT作成アプリ 要件定義書

## 概要

ゲームのスクリーンショットに適用する **LUT**（Look-Up Table、色変換テーブル）を作成するアプリケーション。
色調整パラメータを操作するとLUTが生成され、複数のスクリーンショットに同時適用して仕上がりを確認できる。
生成したLUTはファイルとして書き出し、外部ソフトウェアで利用する。

## 用語

- **LUT**：入力色を出力色に写像するテーブル。本アプリではRGBの3次元LUTを扱う。
- **中立LUT**：すべての入力色をそのまま出力する恒等LUT。調整を適用して生成LUTを作る元になる。
- **調整**：露出やコントラストなど、ユーザーが操作する色変換パラメータの総称。
- **プリセット**：調整パラメータの組を保存したJSON。LUTから調整値への逆変換は原理的に不可能なため、再編集はプリセット経由で行う（仕様決定E）。

## 背景と目的

スクリーンショットの色味を統一したい場合、画像ごとにレタッチするのではなく、変換テーブルを一度作って使い回す方が効率的である。
「作成中のLUTがどの画像にどう効くか」を同時に見比べられることが、このツールの中心価値である。

## スコープ

### 機能要件

| ID | 機能 | 内容 |
|----|------|------|
| F1 | 画像読み込み | PNG、JPEG、WebP等の画像を複数枚読み込む。ドラッグ＆ドロップとファイル選択の両方を受け付ける。枚数に上限は設けず、最低4枚の同時扱いを保証する（仕様決定I） |
| F2 | 色調整 | 露出、コントラスト、彩度、色温度、色相、RGBカーブ、リフト・ガンマ・ゲインを操作できる（仕様決定B）。加えて色相アイソレーション（分離）を操作できる。残したい色相範囲は複数登録でき、選択範囲は色相環グラデーションとプレビューマスクで確認できる（仕様決定K） |
| F3 | LUT生成 | 中立LUTに調整と同じ変換を適用し、LUTデータを生成する。サイズは `.cube` が33、PNGアトラスが64（仕様決定D） |
| F4 | 複数枚プレビュー | 読み込んだ全画像に生成LUTをリアルタイム適用し一覧表示する。各画像で原画像との比較（切替または分割）ができる。プレビュー画像の表示サイズは調整できる（調整ペインは固定幅）。UIテーマはモノクロ基調のダーク・ライトグレー・ブラック・ホワイトを切替できる（仕様決定L） |
| F5 | LUT書き出し | `.cube` とPNG画像LUTで書き出す。PNGはHaldCLUT形式とReShade形式の両方に対応し、書き出し時に選択する（仕様決定A、仕様決定J） |
| F6 | 画像書き出し | LUTを焼き込んだ画像をPNGで保存できる（仕様決定G） |
| F7 | プリセット | 調整パラメータをJSONとして保存・読み込みできる（仕様決定E） |

既存LUTの読み込みは初期スコープ外とする（仕様決定F）。

### 非機能要件

| ID | 項目 | 内容 |
|----|------|------|
| N1 | 実行形態 | 静的Webアプリ。サーバー処理・外部通信を行わず、GitHub Pagesでホストする（仕様決定C） |
| N2 | データ取り扱い | 画像とLUTはブラウザ内で処理し、端末の外へ送信しない |
| N3 | 性能 | 4K程度のスクリーンショット数枚に対し、パラメータ操作中もプレビューが追従する |
| N4 | 対応色域 | SDR（8bit sRGB）を対象とする。HDRは対象外 |

## 実現可能性の検討

「静的Webアプリ」と「スタンドアロンのデスクトップアプリ」のどちらも実現可能である。
採用したのは静的Webアプリである。
理由は三つある。第一に、LUT適用に必要な画像処理はブラウザのWebGLだけでリアルタイムに実現でき、サーバーもインストールも不要になる。第二に、OSを選ばず動作する。第三に、将来デスクトップ化したくなっても同じ実装をTauri等で包めるため、Webから始めても無駄にならない。
デスクトップアプリ（WPF等）も実現可能だが、GPUを使ったリアルタイムプレビューの構築コストがWebより高い。

## 必要な要素

- 画像入力：複数画像の読み込みと管理
- 色調整エンジン：パラメータからピクセル変換を合成する処理系
- LUT生成：中立LUTに同じ変換を適用する処理
- プレビュー描画：全画像へのLUT適用と並列表示
- 書き出し：LUTファイルとLUT適用済み画像の保存

## 技術構成

静的Webアプリとして実装する。
LUT適用はWebGL2の3Dテクスチャで行い、WebGL2が使えない環境では2Dアトラス参照にフォールバックする。
画像は `createImageBitmap` でデコードし、LUTの書き出しはBlobのダウンロードで行う。
配布はGitHub Pagesとし、ビルドが必要な構成でもGitHub Actionsでデプロイする。
